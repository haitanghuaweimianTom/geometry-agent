# Problem: 双曲线 C: 3x²-y²=3, 焦点 F(-2,0), 准线 l: x=-1/2, 顶点 A(-1,0), B(1,0).
# 过 B 的直线交 C 于 N (第二象限), ∠NFB 的角平分线交 BN 于 T.
# (i) 证 T 在定直线上; (ii) 连接 FN 交 C 于 M, 求 k_BN² - k_TM 的范围.

#   → x=1 (B) 或 x=(k²+3)/(k²-3), N=((k²+3)/(k²-3), 6k/(k²-3))
# Step 2: 角平分线定理 |BT|/|TN|=|FB|/|FN|=3/(-2x_N-1)
#   → λ = (3-k²)/(k²+1), T = (B+λN)/(1+λ) = (-1/2, -3k/2)
#   → T_x = -1/2 常数, 故 T 在定直线 x=-1/2 (准线) 上 ✓
# Step 3: FN: y=m(x+2), m=2k/(k²-1), 联立双曲线求 M
#   → 韦达定理: x_N+x_M = 4m²/(3-m²), 得 M=(-(3k²+1)/(3k²-1), 6k/(3k²-1))
# Step 4: 硬算 k_TM
#   → k_TM = (y_M-y_T)/(x_M-x_T) = ... = -3k
# Step 5: k_BN² - k_TM = k² - (-3k) = k² + 3k, k∈(-√3,0), 范围 [-9/4, 0)

# === 方法二: 几何观察 (A,T,M 共线) ===
# Step 1: 验证 A(-1,0), T(-1/2,-3k/2), M 共线
#   → k_AT = (-3k/2)/(1/2) = -3k
#   → k_AM = (6k/(3k²-1))/(-(3k²+1)/(3k²-1)+1) = -3k
#   → k_AT = k_AM → A,T,M 共线 ✓
# Step 2: k_TM = k_AT = -3k, 一步到位, 无需代数通分

# === 方法三: 射影几何 (调和同调) ===
# 准线 l: x=-1/2 是焦点 F 关于双曲线 C 的极线.
# 以 F 为中心、l 为轴的调和同调 H 保 C:
#   H(N) = M (交换焦点弦两端)
#   H(B) = A (交换顶点)
#   H(BN) = AM
# T = BN ∩ l 且 T ∈ l (轴), 故 H(T) = T.
# 因此 T ∈ H(BN) = AM, 即 A,T,M 共线. ∎
# 结果: k_TM = k_AT = -3k.
