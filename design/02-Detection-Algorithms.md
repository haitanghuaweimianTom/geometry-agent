# 02 · 几何对象检测算法设计

> 本文档深入阐述四类核心图元（点、直线、圆、椭圆）的检测算法、网络结构、拟合数学、RANSAC 鲁棒策略与边界处理。感知流水线整体见 [01-Geometry-Parser](./01-Geometry-Parser.md)。

---

## 1. 点检测

点是几何图形中信息密度最高的元素：顶点、交点、切点、圆心、标注点。点检测分为两类来源：**显式点**（图上明确画出的点）与**隐式点**（线段端点、线线交点、线圆交点、圆弧端点）。

### 1.1 检测流水线

```
灰度图 ──▶ 骨架化 ──▶ 端点检测(EDT 端点)
                     │
                     ├──▶ 角点检测(Harris / Shi-Tomasi) ──▶ NMS
                     │
                     └──▶ 交点计算(线-线、线-圆解析求交) ──▶ 合并去重
                                                            │
                                                            ▼
                                          亚像素精修(cornerSubPix) ──▶ Point 列表
```

### 1.2 角点检测
- **Harris**：`cv2.cornerHarris`，响应函数 $R = \det(M) - k\cdot\text{tr}(M)^2$，$M$ 为梯度协方差矩阵。对 L 型角（两线段交点）响应强。
- **Shi-Tomasi**：`cv2.goodFeaturesToTrack`，响应 $R = \min(\lambda_1,\lambda_2)$，更稳定，作为主力。
- **参数**：`maxCorners=200, qualityLevel=0.1, minDistance=10, blockSize=7`。
- **NMS**：在响应图上做非极大值抑制，避免角点聚簇。

### 1.3 端点检测（骨架端点）
骨架（1px 宽）上端点定义为邻域内白色像素数 = 1 的点。
- 用欧氏距离变换（EDT）辅助：端点处 EDT 局部极小。
- 实现：遍历骨架像素，统计 8-邻域白像素数，=1 即端点候选。

### 1.4 交点补全
对已检测的线/圆解析求交，回填为 Point（`source=intersection`）：
- 线-线：解二元一次方程组。
- 线-圆：解二次方程，取实根。
- 圆-圆：解二次方程，取 0/1/2 实交点。

### 1.5 亚像素精修
`cv2.cornerSubPix` 在角点邻域内拟合二次曲面，亚像素定位。迭代终止条件：`criteria=(TERM_CRITERIA_EPS|TERM_CRITERIA_MAX_ITER, 30, 0.01)`。

### 1.6 可选：轻量关键点网络
当传统方法在低质量图上召回不足时，启用轻量网络：
- **输入**：256×256 灰度图块。
- **骨干**：MobileNetV3-small（轻量、单卡可训）。
- **头部**：Heatmap regression（逐像素关键点热图，分辨率 64×64）+ Offset head（亚像素偏移，×0.25 下采样）。
- **损失**：Focal Loss（热图，处理类别不平衡）+ Smooth L1（offset）。
- **训练数据**：程序化合成（见 [09-Dataset](./09-Dataset.md)），无需人工标注。
- **推理**：热图峰值 + offset 精修，再映射回原图坐标。

### 1.7 输出格式
```json
{
  "point_id":"P_001","label":"A","coords":[120.5,88.3],
  "confidence":0.97,"source":"corner","subpixel":true
}
```

## 2. 直线检测

### 2.1 三类方法比较

| 方法 | 原理 | 优点 | 缺点 | 适用 |
| --- | --- | --- | --- | --- |
| Hough 变换 | 参数空间投票 | 鲁棒、抗噪 | 端点不准、参数敏感、无法区分共线段 | 直线方向粗估 |
| LSD（Line Segment Detector） | 梯度场区域生长 | 端点精确、无需调参 | 对噪声敏感、可能过分割 | 主力线段检测 |
| Deep Learning（LETR / HAWP） | 端到端线段检测 | 鲁棒、能学语义 | 需训练、推理慢、几何精度需后处理 | 低质量图备用 |

### 2.2 采用方案：LSD 为主 + Hough 辅助 + 共线合并

```
二值图 ──▶ LSD ──▶ 候选线段集合 {(p1,p2,width)}
                     │
                     ├──▶ 共线段合并(方向+距离+投影重叠)
                     │
                     └──▶ Hough 补充长直线(LSD 漏检)
                            │
                            ▼
                     端点吸附(对齐已检测 Point)
                            │
                            ▼
                     最小二乘拟合直线方程 ──▶ Segment/Line/Ray
```

### 2.3 共线段合并算法
两线段 $s_1=(p_1,p_2)$、$s_2=(q_1,q_2)$ 合并条件：
1. **方向一致**：方向向量夹角 $\theta < 3°$。
2. **共线**：$q_1$（或 $q_2$）到 $s_1$ 所在直线距离 $d < \text{tol}$（tol = max(2px, 1%·线长)）。
3. **投影重叠或邻接**：$q_1,q_2$ 在 $s_1$ 方向上的投影参数区间与 $[0, L_1]$ 间距 < 间隙阈值。

合并后取最远两端点为新端点，重新拟合方程。

### 2.4 直线方程拟合
对属于同一线段的像素集 $\{(x_i,y_i)\}$，最小二乘拟合 $ax+by+c=0$（约束 $a^2+b^2=1$）：
- 中心化：$\bar x, \bar y$。
- 构造协方差矩阵 $M=\begin{bmatrix}\sum (x_i-\bar x)^2 & \sum (x_i-\bar x)(y_i-\bar y) \\ \sum (x_i-\bar x)(y_i-\bar y) & \sum (y_i-\bar y)^2\end{bmatrix}$。
- 最小特征值对应特征向量为 $(a,b)$，$c=-(a\bar x+b\bar y)$。

### 2.5 线段/射线/直线判定
- 两端点都在骨架端点 → **Segment**。
- 一端为端点，另一端延伸出图边/被遮挡 → **Ray**（记录起点+方向）。
- 两端均延伸 → **Line**。
- 歧义时保留多假设。

### 2.6 输出格式
```json
{
  "line_id":"L_003","type":"segment","label":"AB",
  "endpoints":[[120.5,88.3],[210.0,150.0]],
  "equation":{"a":0.62,"b":-0.78,"c":-8.4},
  "length":113.2,"confidence":0.94
}
```

## 3. 圆检测

### 3.1 为什么不只依赖 Hough Circle
Hough Circle 固有缺陷：
- 参数空间（圆心 x、y、半径 r）三维投票，计算量大。
- 对**部分圆（弧）**、**低对比度**、**手绘抖动**鲁棒性差。
- 半径范围需人工设定。
- 多圆共存时易出现假峰。

故本系统采用 **"Mask → 边界提取 → 圆拟合"** 三段式，Hough 仅作候选生成。

### 3.2 三段式圆检测

```
图 像 ──▶ SAM/阈值分割 ──▶ Mask(圆形连通域)
                              │
                              ▼
                       cv2.findContours ──▶ 轮廓点集
                              │
                              ▼
                ┌──────────────────────────┐
                │ 1. Kasa 代数拟合(初值)    │
                │ 2. LM 非线性精修(几何)    │─▶ (圆心,半径,残差)
                │ 3. 残差阈值过滤           │
                └────────────┬─────────────┘
                             ▼
                ┌──────────────────────────┐
                │ 完整性判定(覆盖角度比)    │─▶ 完整圆 / 弧(起止角)
                └──────────────────────────┘
```

### 3.3 Kasa 代数拟合（初值）
最小化代数距离 $\sum (x_i^2+y_i^2+Dx_i+Ey_i+F)^2$。令 $A=D, B=E, C=F$，圆心 $(-D/2,-E/2)$，半径 $r=\sqrt{(D^2+E^2)/4 - F}$。

构造线性方程组求解 $[D,E,F]$：
$$
\begin{bmatrix}
\sum x_i^2 & \sum x_i y_i & \sum x_i \\
\sum x_i y_i & \sum y_i^2 & \sum y_i \\
\sum x_i & \sum y_i & n
\end{bmatrix}
\begin{bmatrix} D \\ E \\ F \end{bmatrix}
=
-\begin{bmatrix} \sum x_i(x_i^2+y_i^2) \\ \sum y_i(x_i^2+y_i^2) \\ \sum (x_i^2+y_i^2) \end{bmatrix}
$$

### 3.4 Levenberg-Marquardt 几何精修
Kasa 最小化代数距离（有偏），LM 最小化**几何距离** $\sum (\sqrt{(x_i-c_x)^2+(y_i-c_y)^2} - r)^2$。以 Kasa 解为初值，迭代收敛至几何最优。实现：`scipy.optimize.least_squares(method='lm')`。

### 3.5 完整性判定
统计轮廓点相对圆心的角度分布：
- 计算每个点角度 $\alpha_i = \text{atan2}(y_i-c_y, x_i-c_x)$。
- 角度覆盖范围 = 最大连续覆盖弧度（处理跨 ±π）。
- 覆盖 ≥ 330°（≈5.76 rad）→ **完整圆**。
- 否则 → **Arc**，记录起止角。

### 3.6 残差阈值与多圆处理
- **合格判定**：平均径向误差 `mean(|dist_i - r|) / r < 3%`。
- **多圆**：每个连通域独立拟合。
- **残差过大**：尝试分解为"圆+弧"组合，或降级为低置信候选。
- **同心圆**：圆心距离 < tol 的多个圆，标记 `concentric`（在 Relation 层处理）。

### 3.7 输出格式
```json
{
  "circle_id":"C_001","label":"O",
  "center":[180.0,160.0],"radius":75.5,
  "fit_residual":1.2,"coverage":1.0,
  "arc_range":null,"confidence":0.96
}
```

## 4. 椭圆检测

### 4.1 三段式椭圆检测

```
图 像 ──▶ Mask(SAM/阈值) ──▶ Contour ──▶ Ellipse Fitting ──▶ Ellipse 对象
                                            │
                                            ├── 倾斜椭圆? ▶ 直接拟合(含旋转角)
                                            ├── 低质量图? ▶ RANSAC 鲁棒拟合
                                            └── 手绘图?   ▶ 多假设+残差择优
```

### 4.2 Fitzgibbon 直接最小二乘（初值）
椭圆方程 $Ax^2+Bxy+Cy^2+Dx+Ey+F=0$，约束 $B^2-4AC<0$。Fitzgibbon 方法在约束 $4AC-B^2=1$ 下最小化代数距离，化为广义特征值问题：

$$
M\,u = \lambda\, N\, u
$$

其中 $u=[A,B,C,D,E,F]^T$，$M$ 为数据矩阵，$N$ 为约束矩阵。取满足约束的特征向量。结果含旋转角 $\theta=\frac12\text{atan2}(B, A-C)$，长/短半轴由特征值给出。

OpenCV 提供 `cv2.fitEllipse`（基于 Fitzgibbon），直接返回旋转矩形 `(center, axes, angle)`。

### 4.3 非线性精修
以 Fitzgibbon 解为初值，LM 最小化几何距离 $\sum (\text{dist}(p_i, \text{ellipse})^2)$。点到椭圆距离用近似迭代（Taubin distance）计算。

### 4.4 RANSAC 鲁棒拟合（手绘/噪声图）
1. 随机采样 5~6 点。
2. `cv2.fitEllipse` 拟合。
3. 计算所有轮廓点的几何距离，统计内点（距离 < 阈值）。
4. 重复 N 次（N 自适应：$N=\log(1-p)/\log(1-w^s)$，$p=0.99$，$w$ 内点率估计，$s=5$）。
5. 取内点最多的一组，对所有内点做 LM 精修。

### 4.5 焦点计算
由拟合参数 $(c_x,c_y,a,b,\theta)$：
- $c=\sqrt{a^2-b^2}$（$a\ge b$ 为半长轴）。
- 焦点 $F_{1,2} = (c_x \pm c\cos\theta,\ c_y \pm c\sin\theta)$。
- 离心率 $e=c/a$。

### 4.6 难点处理

| 难点 | 处理策略 |
| --- | --- |
| 倾斜椭圆 | 拟合输出含旋转角 θ，长轴方向由特征向量给出，无需额外处理 |
| 低质量图 | RANSAC + 多假设择优；与 Hough 椭圆候选交叉验证 |
| 手绘抖动 | 加大 RANSAC 内点阈值；B 样条平滑后再拟合；残差过大降级"近似椭圆"低置信 |
| 部分椭圆 | 角度覆盖判定，标记为椭圆弧 |
| 圆 vs 椭圆歧义 | 若 $a/b < 1.05$ 且拟合为圆残差也合格，保留双假设（圆+椭圆），交 LLM 消歧 |

### 4.7 输出格式
```json
{
  "ellipse_id":"E_001","label":"E",
  "center":[200.0,180.0],"semi_major":90.0,"semi_minor":50.0,
  "rotation":0.35,
  "foci":[[243.2,195.3],[156.8,164.7]],
  "eccentricity":0.83,"fit_residual":2.1,"confidence":0.91
}
```

## 5. 检测准确率保障机制

为满足"高准确率优先"原则，检测层引入三重保障：

### 5.1 置信度门控
低置信原语（confidence < 0.6）标记 `uncertain`，进入 Verifier 复核而非直接入图。

### 5.2 跨原语一致性
- 线段端点应与点检测吻合（距离 < 3px）。
- 圆上点应满足距离 ≈ 半径（容差内）。
- 共线段应被合并。
- 矛盾项触发重检测或降级。

### 5.3 多假设保留
对歧义图元保留多个候选（如线段/射线、圆/椭圆），交由后续 LLM + Verifier 在解题上下文中消歧。这是"高准确率优先 + 不丢召回"的折中。

### 5.4 合成数据回归测试
对每类检测器，用程序化合成图（带 ground truth）建立回归测试集，每次迭代检测准确率，防止改动回退。

## 6. 设计路线小结

| 图元 | 主算法 | 精修 | 鲁棒策略 |
| --- | --- | --- | --- |
| 点 | Harris/Shi-Tomasi + EDT 端点 + 解析交点 | cornerSubPix 亚像素 | 轻量网络补漏 |
| 直线 | LSD + Hough 辅助 | 最小二乘方程 | 共线段合并 |
| 圆 | Mask + 轮廓 + Kasa | LM 几何拟合 | 残差过滤 + 弧判定 |
| 椭圆 | Mask + 轮廓 + Fitzgibbon | LM 非线性 | RANSAC + 多假设 |

所有算法遵循"**代数初值 → 几何精修 → 残差门控 → 多假设保留**"的统一路线，兼顾精度、鲁棒性与可解释性。
