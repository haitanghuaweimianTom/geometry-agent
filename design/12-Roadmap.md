# 12 · 开发路线图

> 本文档阐述系统的五阶段开发路线，每阶段的任务分解、依赖关系、验收指标、里程碑与风险对策。采用渐进式开发，每阶段聚焦一类几何对象，逐步逼近完整中高考题。

---

## 1. 路线图总览

```
Phase 1: 三角形+直线 ──▶ Phase 2: 圆 ──▶ Phase 3: 椭圆 ──▶ Phase 4: 完整题 ──▶ Phase 5: 自动证明
   (MVP 基础题)         (含圆题)         (含椭圆题)        (真题综合)        (Lean 校验)
```

| 阶段 | 目标 | 对象 | 验收指标 | 周期（建议） |
| --- | --- | --- | --- | --- |
| Phase 1 | 三角形 + 直线 | 点、线段、三角形、平行/垂直/等长标记 | 基础题准确率 ≥ 80% | 6~8 周 |
| Phase 2 | 圆 | 圆、弧、切线、圆周角、圆幂 | 含圆题准确率 ≥ 75% | 4~6 周 |
| Phase 3 | 椭圆与二次曲线 | 椭圆、焦点、切线 | 含椭圆题准确率 ≥ 70% | 3~5 周 |
| Phase 4 | 完整中高考题 | 综合题、动态几何 | 真题综合准确率 ≥ 70% | 4~6 周 |
| Phase 5 | 自动证明 | Lean 形式化、自研引擎完善 | 证明机器可校验 | 4~8 周 |

---

## 2. Phase 1：三角形 + 直线（MVP）

### 2.1 目标
搭建端到端最小可用系统，可解"求角度/长度/平行垂直"基础题。

### 2.2 任务分解

| 模块 | 任务 | 依赖 |
| --- | --- | --- |
| 感知 | Preprocess、Point/Line Detector、共线段合并 | — |
| 结构化 | Graph Schema、Builder、Point/Line Agent | 感知 |
| 验证 | On/Collinear/Parallel/Perpendicular/Equal Verifier | 结构化 |
| DSL | 语法子集、序列化器、解析器 | 结构化 |
| 推理 | LLM Agent(CoT)、Prompt 模板、Tool Calling | DSL |
| 求解 | SymPy Engine、基础定理库（勾股/相似/全等） | 推理 |
| 数据 | 三角形合成引擎（5k）+ 真题 200 | — |
| 工程 | FastAPI、Pipeline、Docker、日志 | 全部 |

### 2.3 验收
- 合成三角形题准确率 ≥ 85%。
- 真题基础题准确率 ≥ 80%。
- 端到端可运行（图片→答案）。
- verification_log 完整。

---

## 3. Phase 2：圆

### 3.1 目标
扩展圆相关能力，可解切线、圆周角、弦长、两圆关系题。

### 3.2 任务分解

| 模块 | 任务 | 依赖 |
| --- | --- | --- |
| 感知 | Circle Detector（三段式）、Arc Detector | Phase 1 |
| 结构化 | Circle Agent（切线/割线/弦/圆周角/两圆/切点/圆幂） | 感知 |
| 验证 | Tangent/OnCircle/Concentric/Inscribed Verifier | 结构化 |
| DSL | 圆关系关键字扩展 | 结构化 |
| 推理 | 圆相关 Few-shot、定理 RAG 扩展 | DSL |
| 求解 | 圆定理规则引擎（R1/R2 圆周角/切线性质） | 推理 |
| 数据 | 含圆合成题 10k + 真题 300 | — |

### 3.3 验收
- 含圆合成题准确率 ≥ 80%。
- 真题含圆题准确率 ≥ 75%。
- 圆相关验证器回归测试通过。

---

## 4. Phase 3：椭圆与二次曲线

### 4.1 目标
扩展椭圆能力，可解椭圆定义、焦点、切线题。

### 4.2 任务分解

| 模块 | 任务 | 依赖 |
| --- | --- | --- |
| 感知 | Ellipse Detector（Fitzgibbon + LM + RANSAC） | Phase 1 |
| 结构化 | Ellipse Agent（焦点关系/切线/顶点） | 感知 |
| 验证 | EllipseSumVerifier、椭圆切线 Verifier | 结构化 |
| DSL | 椭圆关键字扩展 | 结构化 |
| 推理 | 椭圆 Few-shot、椭圆定理 RAG | DSL |
| 求解 | 椭圆规则（R5 椭圆定义） | 推理 |
| 数据 | 椭圆合成题 5k + 真题 100 | — |

### 4.3 验收
- 含椭圆合成题准确率 ≥ 75%。
- 真题含椭圆题准确率 ≥ 70%。

---

## 5. Phase 4：完整中高考题

### 5.1 目标
整合所有对象，引入高级推理范式，可解综合题与动态几何。

### 5.2 任务分解

| 模块 | 任务 | 依赖 |
| --- | --- | --- |
| 推理 | ToT 搜索、Self-Reflection、Self-Consistency Voting | Phase 1~3 |
| 求解 | Z3 集成（动点范围/反例）、自研引擎完善 | 推理 |
| 数据 | 真题评估集 500+，迭代优化 | — |
| 工程 | 性能优化（并行/缓存）、监控完善 | 全部 |
| 评测 | 真题综合准确率跟踪 | — |

### 5.3 验收
- 真题综合准确率 ≥ 70%。
- 幻觉率 < 5%（未验证关系进入结论比例）。
- 端到端延迟 P95 < 60s。

### 6.1 目标

### 6.2 任务分解

| 模块 | 任务 | 依赖 |
| --- | --- | --- |
| 求解 | Lean 4 集成、Graph→Lean 翻译器 | Phase 4 |
| 求解 | 自研引擎规则扩充（覆盖主流定理） | Phase 4 |
| 推理 | 证明链→Lean tactic 翻译 | 求解 |
| 评测 | 证明机器可校验率跟踪 | — |

### 6.3 验收
- 证明 Lean 校验通过率 ≥ 60%。
- 自研引擎可自动推导 ≥ 80% 基础关系。

---

## 7. 里程碑

```
M1 (Phase 1) ──▶ M2 (Phase 2) ──▶ M3 (Phase 3) ──▶ M4 (Phase 4) ──▶ M5 (Phase 5)
 基础题可用       含圆题可用         含椭圆题可用      真题综合可用      证明可校验
```

每里程碑交付：可运行系统 + 评估报告 + 回归测试集。

---

## 8. 依赖与并行

- Phase 1 是所有后续阶段的基础（核心管线）。
- Phase 2/3 的感知/Agent 可并行开发（不同人负责）。
- Phase 4 依赖 1~3 完成。
- Phase 5 可与 Phase 4 后期并行启动（Lean 集成独立）。

---

## 9. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 手绘图质量差 | 检测召回下降 | RANSAC + 多假设 + 低置信标记 |
| LLM 幻觉 | 编造未验证关系 | 强制 Tool Calling + Verifier 闭环 |
| 关系歧义 | 多候选无法消歧 | 保留多假设，LLM 在上下文消歧 |
| 定理库不全 | RAG 漏检 | 持续扩充 + 教材整理 |
| 计算延迟 | 多 Agent + ToT 慢 | 并行化 + 路径剪枝 + 缓存 |
| 合成→真实域差距 | 真题准确率低 | 风格增强 + 真题精标迭代 |
| Phase 5 Lean 成本高 | 延期 | 可选阶段，不阻塞主线 |

---

## 10. 评估与迭代

每阶段结束：
- 跑合成回归集（防回退）。
- 跑真题评估集（跟踪真实能力）。
- 复盘失败案例，定位模块（感知/关系/验证/推理/求解）。
- 针对性优化（数据/算法/Prompt/规则）。

迭代以**数据驱动**：失败案例→分析→补充数据/规则→回归验证。

---

## 11. 设计路线小结

开发路线图的设计路线为：**"五阶段渐进(三角形→圆→椭圆→综合→证明) → 每阶段任务分解+依赖+验收 → 里程碑交付 → 并行优化 → 风险对策 → 数据驱动迭代"**。从 MVP 到完整系统，每阶段可独立交付价值，风险可控，逐步逼近"高准确率、可解释、可验证"的最终目标。
