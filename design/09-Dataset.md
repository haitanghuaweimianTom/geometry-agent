# 09 · 数据集设计

> 本文档阐述数据集的类型与格式、标注 Schema、程序化合成引擎、风格增强、真题标注流程与数据质量评估。数据是"无后训练"范式下的关键杠杆。

---

## 1. 设计目标

在无法大规模后训练的约束下，数据的作用转变为：
1. 训练轻量检测器（标注符号 YOLO、可选关键点网络）。
2. 评估各模块准确率（有 ground truth）。
3. 构建 Few-shot 示例库与定理库。
4. 回归测试防回退。

故数据集设计遵循**低成本、程序化为主、人工为辅**原则。

---

## 2. 数据类型与格式

| 数据集 | 内容 | 格式 | 用途 |
| --- | --- | --- | --- |
| GeoImage | 几何图片（合成+真实） | PNG + JSON 标注 | 检测器训练/评估 |
| GeoGraph | Geometry Graph 标注 | JSON | Graph 构建、关系抽取评估 |
| GeoDSL | DSL 标注 | YAML | LLM Prompt、Few-shot |
| GeoProof | 证明步骤 | JSON (step+reason) | 推理评估、SFT（可选小量） |
| TheoDB | 几何定理库 | 结构化条目 | RAG 检索 |

---

## 3. 标注格式（COCO-like 扩展）

```json
{
  "image": "synth_000123.png",
  "size": [400, 320],
  "objects": [
    {"type":"Point","label":"A","coords":[180,84]},
    {"type":"Circle","label":"O","center":[180,160],"radius":75.5},
    {"type":"Segment","label":"AB","endpoints":[[180,84],[260,140]]}
  ],
  "relations": [
    {"rel":"On","src":"A","dst":"O"},
    {"rel":"Tangent","src":"AB","dst":"O","at":"A"},
    {"rel":"Perpendicular","src":"OA","dst":"AB"}
  ],
  "dsl": "<对应 DSL>",
  "proof": [
    {"step":1,"statement":"...","reason":"..."}
  ],
  "answer": "AB·AC = AD·AE",
  "problem_text": "如图，AB 切圆 O 于 A..."
}
```

标注格式与 Geometry Graph/DSL 双向兼容，一套标注支持多模块评估。

## 4. 程序化合成引擎

合成是数据的主要来源，零标注成本、可无限生成。

### 4.1 引擎架构

```
┌──────────────┐   ┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│ Template Pool│──▶│ Param Sampler│──▶│ Geometry     │──▶│ Renderer     │
│ 题型模板      │   │ 随机参数      │   │ Constructor  │   │ matplotlib   │
│              │   │              │   │ (构建图+GT)   │   │ + cairo      │
└──────────────┘   └──────────────┘   └──────┬───────┘   └──────┬───────┘
                                              │                  │
                                              ▼                  ▼
                                       Graph + DSL + Proof   PNG 图像
                                              │
                                              ▼
                                       风格增强(噪声/抖动/手绘)
```

### 4.2 题型模板
按几何对象分类模板：
- `triangle_basic`：随机三角形 + 角度/长度标注。
- `circle_tangent`：随机圆 + 切线 + 切点。
- `circle_inscribed_angle`：圆上多点 + 圆周角。
- `ellipse_focus`：椭圆 + 焦点 + 椭圆上点。
- `similar_triangle`：相似三角形构图。
- `two_circles`：两圆关系（外切/相交/...）。

每个模板定义：参数空间、构图规则、自动生成 GT（Graph/DSL/Proof）。

### 4.3 参数采样
- 坐标在画布范围内均匀采样。
- 角度/长度约束满足几何有效性（如三角形两边之和 > 第三边）。
- 标签按 A,B,C,... 顺序分配。
- 随机决定是否添加标注符号（角标/等长/平行）。

### 4.4 构造器（Geometry Constructor）
根据模板与参数，构造几何对象并**自动推导**全部关系（用解析几何），生成：
- `PrimitiveSet`（GT）
- `GeometryGraph`（GT，所有关系 verified=true）
- `DSL`
- `Proof`（若模板含证明模板，填充具体数值）

### 4.5 渲染器
- matplotlib + cairo 渲染为 PNG，线宽/字体可控。
- 模拟试卷风格：白底黑线、标签字体、标注符号。
- 输出原图 + GT 标注 JSON。

### 4.6 规模
可无限生成，目标：
| 数据集 | 量级 |
| --- | --- |
| GeoImage (合成) | 100k+ |
| GeoProof (合成) | 10k |

## 5. 风格增强

合成图与真实试卷存在域差距，需风格增强提升泛化：

| 增强 | 方法 | 目的 |
| --- | --- | --- |
| 高斯噪声 | 叠加随机噪声 | 模拟低质量扫描 |
| 抖动 | 线段像素随机偏移 | 模拟手绘抖动 |
| 倾斜 | 随机旋转 ±5° | 模拟拍摄倾斜 |
| 光照不均 | 叠加渐变 | 模拟光照 |
| 手绘风格迁移 | GAN/风格迁移或简化笔触模拟 | 模拟手绘图 |
| 字体变化 | 多种字体渲染标签 | 模拟不同试卷 |
| 模糊 | 高斯模糊 | 模拟失焦 |

增强后重新生成 GT（保持几何关系不变，仅像素变化）。

## 6. 真题标注流程

合成数据无法完全覆盖真实试卷的多样性，需小量真题精标。

### 6.1 流程
1. **收集**：从中高考真题、教辅收集 500~1000 张几何图。
2. **VLM 预标注**：用 VLM（Qwen-VL/GPT-4V）预标注对象与关系，降低人工成本。
3. **人工校正**：标注员校正预标注，确保 GT 准确。
4. **交叉校验**：双人标注 + 仲裁，保证质量。
5. **入库**：作为评估集（hold-out）与微调小模型用。

### 6.2 标注工具
自研轻量 Web 标注工具（基于 LabelMe 扩展），支持：
- 点/线/圆/椭圆绘制。
- 关系标注（连线 + 关系类型）。
- 标签关联。
- 自动导出标准 JSON。

### 6.3 规模
| 数据集 | 量级 |
| --- | --- |
| GeoImage (真实) | 1k~2k |
| GeoProof (真题) | 1k |

## 7. 定理库构建

### 7.1 来源
从教材（人教版初高中）、题库整理 200~500 条几何定理。

### 7.2 结构化
每条定理 `(id, name, premise, conclusion, condition, category, reference)`（见 [08-Solver §3](./08-Symbolic-Solver.md)）。

### 7.3 向量化
按 `name + premise + conclusion` 向量化，存入 FAISS/Chroma，供 RAG 检索。

## 8. 数据质量评估

### 8.1 合成数据质量
- **几何有效性**：自动校验合成图关系自洽（如三角形不等式）。
- **渲染正确性**：抽样人工检查图像与 GT 一致。
- **多样性**：统计参数分布，避免模式单一。

### 8.2 真题标注质量
- **双人一致率**（Cohen's κ）：目标 > 0.85。
- **仲裁机制**：不一致项第三人仲裁。
- **抽样复审**：10% 抽样复审。

### 8.3 评估集划分
- 合成数据：训练/验证。
- 真题数据：评估（hold-out，绝不参与训练/微调），反映真实泛化能力。

| 指标 | 说明 |
| --- | --- |
| 题型分布 | 各题型样本数，避免偏斜 |

| 关系频率 | 各关系类型频率 |
| 难度分布 | 简单/中/难比例 |
| 标注一致率 | κ 系数 |

数据集版本化（DVC 或 git-lfs），每次迭代记录变更。

---

## 10. 设计路线小结

数据集设计路线为：**"统一标注 Schema → 程序化合成引擎(模板+参数+构造器+渲染器) → 风格增强(缩小域差距) → 真题小量精标(VLM 预标注+人工校正) → 定理库结构化 → 质量评估(一致率/分布) → 评估集 hold-out"**。以零成本合成为主、真题精标为辅，在无后训练约束下为各模块提供训练与评估支撑。
